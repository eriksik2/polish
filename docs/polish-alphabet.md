# Polish Alphabet — Reference for the App

> **Sources:** [Wikipedia: Polish alphabet](https://en.wikipedia.org/wiki/Polish_alphabet), [Wiktionary: Polish pronunciation](https://en.wiktionary.org/wiki/Appendix:Polish_pronunciation), [Polish Academy orthography conventions](https://en.wikipedia.org/wiki/Polish_orthography).  
> This document is the canonical reference for letter lessons and exercise content. Update lessons when this doc changes.

## Overview

The Polish alphabet has **32 letters** used in native words: **9 vowels** and **23 consonants**. It is based on Latin script with **9 diacritic letters**: ą, ć, ę, ł, ń, ó, ś, ź, ż.

Letters **q, v, x** appear only in loanwords and abbreviations. This app's alphabet module covers the **32 native letters** only.

### Key principles for learners

1. **Most letters sound the same everywhere in a word** — unlike English, spelling is largely phonetic.
2. **One letter (or digraph) ≈ one sound** in standard reading.
3. **Diacritics mark distinct sounds**, not optional decoration.
4. **i softens the preceding consonant** before another vowel (e.g. *ci* → /t͡ɕ/, *ni* → /ɲ/).
5. **Stress** is usually on the **penultimate** (second-to-last) syllable.
6. **Nasal vowels** ą and ę change before certain consonants and word-finally.

## Vowels (9)

| Letter | Polish name | IPA | English approximation | Notes | Example words |
|--------|-------------|-----|----------------------|-------|---------------|
| **A** a | a | /a/ | **ah** as in *father* | Slightly more frontal between palatalized consonants | **a**uto, m**a**ma, t**a**m |
| **Ą** ą | ą | /ɔw̃/ | **own** (nasal) | Nasal o; before *w* becomes /ɔ/; variants [ɔn ŋ ɔm] before fricatives | g**ą**ś, m**ą**ż, w**ą**ch |
| **E** e | e | /ɛ/ | **eh** as in *bed* | Can be [e] between palatalized consonants | **e**l**e**kt**y**ka, t**e**n |
| **Ę** ę | ę | /ɛw̃/ | **en** (nasal) as in *end* with nose | Nasal e; word-finally often /ɛ/; before *w* → /ɛ/ | g**ę**ś, j**ę**zyk, im**ę** |
| **I** i | i | /i/ | **ee** as in *feet* | Also marks consonant softening before vowels; as /j/ before consonant | **i**d**ę**, p**i**wo, m**i**eć |
| **O** o | o | /ɔ/ | **aw** as in *caught* (without cot-caught merger) | [o] between palatalized consonants | **o**ko, r**o**k, m**o**rze |
| **Ó** ó | ó | /u/ | **oo** as in *boot* | Same sound as **u**; ó used after consonants, u after vowels & word-initially | b**ó**g, g**ó**ra, kr**ó**l |
| **U** u | u | /u/ | **oo** as in *boot* | Same as ó; sometimes [w] after vowels | **u**lica, d**u**ży, t**u** |
| **Y** y | y (igrek) | /ɨ/ | **i** as in *bit* or *roses* | **Not** the same as Polish **i**; central vowel, no exact English match | m**y**, d**y**wan, **y**y |

## Pairs learners often confuse

| Pair | Distinction |
|------|-------------|
| **ó / u** | Same sound /u/; different spelling rules only |
| **h / ch** | Same sound /x/ in modern Polish |
| **i / y** | /i/ (feet) vs /ɨ/ (bit/roses) — completely different vowels |
| **e / y** | /ɛ/ (bed) vs /ɨ/ (bit) |
| **ł / l** | /w/ (will) vs /l/ (light) |
| **w / ł** | /v/ (vow) vs /w/ (will) — **opposite of English!** |
| **ą / ę** | /ɔw̃/ (nasal aw) vs /ɛw̃/ (nasal eh) |
| **c / cz** | /ts/ vs /tʂ/ (harder "ch") — cz is a digraph, not in single-letter module |
| **ś / sz** | Soft /ɕ/ vs hard /ʂ/ — sz is digraph |
| **ć / cz** | Soft /t͡ɕ/ vs hard /t͡ʂ/ |
| **ń / n** | /ɲ/ (canyon) vs /n/ (no) |
| **ź / ż** | Soft /ʑ/ vs hard /ʐ/ |
